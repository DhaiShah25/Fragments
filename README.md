# Fragments

A simple game currently programmed using Raylib. I plan to eventually turn this into a 3d game using
vulkan for graphics. The Raylib version will have placeholder assets on completion but the gameplay
loop should be mostly defined. Also, the spells will not have proper artwork nor particle effects in
the Raylib variant of the game. The Raylib version is to build a basic gameplay loop without
having to worry about the complexities of a finalized 3d project. Features **will** be incomplete.

# Game Lore

In the game the player is a novice sorcerer. They miscast a hex which caused them to pass out, which
is the opening sequence for the game. When they awaken, they awaken into a cursed library. The goal
of the game is for them to return home after addressing the problems that trapped them here. Enemies
are drop spell shards which can be combined with varying degrees of success. Spells can be combined
with one another. You can only have 2 spells equipped at once and the remaining stay in your spell
book. The player has to explore procedurally generated levels in order to escape. They are all
procedurally generated and changed on each playthrough. The spell crafting table should has six slots.
A mini puzzle game is played for the merging / creation of spells.
