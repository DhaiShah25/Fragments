# Fragments

A simple game currently programmed using Raylib. I plan to eventually turn this into a 3d game using
vulkan for graphics. The Raylib version will have placeholder assets on completion but the gameplay
loop should be mostly defined. The Raylib version is to build a basic gameplay loop without
having to worry about the complexities of a finalized 3d project. Features **will** be incomplete.

# Game Lore

In the game the player is a novice sorcerer. They miscast a hex which caused them to pass out.
When they awaken, they awaken into a cursed library. The goal of the game is for them to return home.
The player has to explore procedurally generated levels in order to escape. The maze progressively gets
more complicated. They are all procedurally generated and changed on each playthrough. Their goal is
to escape the 10 floors and return back to the real world.

# Controls

The game uses standard WASD for movement and uses right-click to dash.
